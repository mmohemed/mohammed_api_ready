# 📱 تطبيق المشرفين (Flutter)

تطبيق جوال للمشرفين ومدراء المصنع: تسجيل دخول، مؤشرات المصنع، خطر عطل الآلات، والرؤى الذكية — يتصل بنفس خادم النظام.

> **ملاحظة**: هذا هيكل جاهز للبناء يتطلب تثبيت Flutter SDK على جهاز التطوير.
> الواجهة الرئيسية للنظام متجاوبة أصلًا وتعمل من متصفح الجوال مباشرة
> (افتح `http://عنوان-الخادم:8000` من جوالك على نفس الشبكة) — استخدم هذا التطبيق
> إذا أردت تجربة تطبيق أصلي (Native) بإشعارات لاحقًا.

## البناء والتشغيل

```bash
# 1) ثبّت Flutter: https://docs.flutter.dev/get-started/install
# 2) عدّل عنوان الخادم في lib/main.dart:
#    const String serverUrl = 'http://192.168.1.50:8000';
cd mobile_app
flutter pub get
flutter run                # للتجربة على جهاز/محاكي متصل
flutter build apk          # لإنتاج APK للأندرويد
```

## الشاشات الحالية
- تسجيل الدخول (نفس حسابات النظام)
- لوحة المشرف: مؤشرات KPI، خطر عطل كل آلة بالألوان، والرؤى والتوصيات بالأولوية
- تحديث بالسحب للأسفل (Pull to refresh)

## أفكار للتوسعة
- إشعارات فورية عند خطر عطل مرتفع (Firebase Cloud Messaging)
- تسجيل قراءات الحساسات من الجوال
- الموافقة على طلبات الشراء من الجوال
